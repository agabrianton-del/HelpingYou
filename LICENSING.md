# Estrategia de Licenciamiento

## Modelo actual

- El código fuente público del repositorio se distribuye bajo **GNU AGPLv3**.
- Las marcas y la identidad visual (incluida **“Tikkun”**) se rigen por [TRADEMARKS.md](TRADEMARKS.md).
- Las contribuciones están sujetas a [CLA.md](CLA.md).

## Modelo futuro de doble licencia

El proyecto podrá ofrecer un modelo dual:

1. **Edición comunitaria AGPLv3:** seguirá disponible para la comunidad bajo AGPLv3.
2. **Licencia comercial:** podrá ofrecerse a organizaciones que necesiten términos no copyleft o condiciones comerciales específicas.

## Condiciones para la licencia comercial

- La licencia comercial no reemplaza la AGPLv3 del repositorio público.
- La licencia comercial se ofrecerá mediante acuerdo separado.
- La base legal para relicenciamiento proviene del CLA aceptado por contribuidores.
